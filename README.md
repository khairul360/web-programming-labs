# Web Programming Labs

Coursework from my Computer Science degree (FSKTM, UTHM), collected in one place. The labs move from front-end JavaScript through to a database-backed PHP application.

## Contents

### [`lab4`](lab4) — JavaScript DOM basics
Events, input validation and dynamically generated content with plain JavaScript.
**Tech:** HTML5 · JavaScript

### [`lab4b`](lab4b) — JSON data & jQuery
Reading structured JSON data and manipulating the page with jQuery (changing text, toggling classes, click handlers).
**Tech:** HTML5 · JavaScript · JSON · jQuery

### [`lab5`](lab5) — PHP & MySQL
PHP fundamentals plus a small user-management system: registration, secure login (bcrypt + sessions) and full CRUD on users, using prepared statements.
**Tech:** PHP · MySQL · HTML/CSS

## Running the labs
- **lab4 / lab4b:** open the `.html` files in a browser. No build step.
- **lab5:** needs PHP and MySQL (XAMPP/MAMP). See [`lab5/README.md`](lab5/README.md) for database setup.
