# JavaScript DOM Basics

Three short exercises in plain JavaScript that manipulate the page in the browser. They were written as university web-programming coursework.

| File | What it shows |
|------|---------------|
| `task1.html` | Changing an element's content with a button click |
| `task2.html` | Reading user input, validating it and branching on the result |
| `task3.html` | Building page content with a loop on page load |

**Tech:** HTML5 · JavaScript (ES6)

## Run it
Open any `.html` file in a browser. No build step is needed.
