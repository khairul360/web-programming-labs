# JSON Data & jQuery DOM Operations

Exercises in working with structured JSON data and manipulating the DOM with jQuery. They were written as university web-programming coursework.

| File | What it shows |
|------|---------------|
| `index.html` | Reading a list of books, picking out fields, and flattening and listing genres with `map`/`flat` |
| `books.json` | Sample book data (title, author, year, genres) |
| `question3.html` | jQuery: changing text, adding CSS classes and handling click events |

**Tech:** HTML5 · JavaScript (ES6) · JSON · jQuery 3.7

## Run it
Open `index.html` or `question3.html` in a browser.
